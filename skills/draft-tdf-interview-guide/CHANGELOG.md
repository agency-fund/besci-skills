# Changelog

## 0.3.0 - 2026-11-11
Follows the conversational-voice standard (ADR 0009). The guide opens with a few plain sentences to the user (how many questions, how they cover each hypothesis and the domains with none, and the one thing to settle before the first interview), and the opening's "Reconstruction" question is labeled "The last time it was due". The output ends with next moves and their reasons, chosen from candidates listed in the closing, and the skill carries the shared voice block. The method is unchanged. Edited with Claude.

(2012), table 3, which corrects two rows; the domain list moved to `references/tdf-domains.md`. Every source was rechecked, and studies that used the framework in Kenya, Nigeria, South Africa, and India were added. Rewritten with Claude.
