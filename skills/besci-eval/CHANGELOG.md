# Changelog

## 0.4.0 - 2026-11-25
Rewritten in its own shape, without the eight sections or the shared voice block. The main test is now a comparison: each case is answered with the skill and with no skill, and the evaluator asks what the skill changed, whether the change is what the skill promises, and which answer a practitioner would prefer. The nine-criterion rubric scored out of 18 is gone, and `references/judging.md` replaces `references/rubric.md`; three blocking findings remain (an invented citation, answering when it should have asked, a missed handoff). The evaluator runs three cases by default: Full run, Missing context, and a cold case it writes from the description alone before reading the skill. It runs them with fresh agents where it can, with the script for repeats and model comparisons, and in conversation otherwise. The report is one screen with a fixed order and gives triggering as counts in words. Because the comparison needs no fixed sections, it works on meta-skills and supporting skills. In `run_evals.py` the comparison with no skill is the default (`--skip-bare` turns it off), the judge compares the two answers without being told which is which, a cold case is written unless `--cold` or `--no-cold` is given, `--all-cases` runs every case, a case can carry `"should_trigger": false`, and the neighbor descriptions are read from the catalog snapshot correctly. Edited with Claude.

## 0.3.0 - 2026-11-11
Adds a ninth rubric criterion, Conversation: answers what was asked before offering the run, marks the run, says where claims come from, and ends with next moves and their reasons. "Asked first" no longer penalizes a brief answer before the questions. Totals are out of 18; "ready" is a median of 16 or more. The report opens with a few plain sentences, "Next actions for the author" becomes "What would raise the score", and it ends with next moves and carries the shared voice block. Bundles the updated validator and checklist. Edited with Claude.

## 0.2.0 - 2026-11-10
Grades each output against the test case's own assertions as well as the rubric, and adds `--no-skill-baseline`, which runs the same cases with no skill loaded to show what the skill adds. Expects the four named test cases of the November 2026 standard. Edited with Claude.

## 0.1.0 - 2026-10-08
First version. Structure, triggering, and output-quality checks; rubric derived from the eight sections; API runner for cross-model comparison with baseline support. Five evals. Not yet reviewed. The partnership plans to deepen this skill together once real skills exist to evaluate; expert ratings are a later-phase feature.
