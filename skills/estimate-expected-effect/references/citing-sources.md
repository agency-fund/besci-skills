# Citing sources

Rules for a skill that searches for studies or reads the studies it is given. A citation that looks right and is wrong does more harm than no citation.

1. **Open every source before citing it.** Confirm the authors, the year, and the title against the page you opened, not against memory.
2. **Take numbers from the results.** Report an effect size only from the paper's results section or tables, with its unit. If you read only the abstract, write "abstract only" beside the citation.
3. **Give a link only if you opened it and it showed the source.** Prefer the DOI link. Drop a source whose link does not resolve.
4. **Say "no evidence found" when no study addresses the claim.** List the nearest related studies and say how each differs from the claim. Do not issue a verdict the evidence does not support.
5. **Keep what you did not read separate.** A study known only from another paper's reference list is written "cited in <source>, not read".
6. **If no search tool is available, say so in the first line of the output.** Mark each citation "from memory, not checked", and give no links and no effect sizes.
